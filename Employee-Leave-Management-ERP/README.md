# ERP-Based Employee Leave Management System using Odoo

## 📌 Project Overview

This project demonstrates the end-to-end Business Analysis process for implementing an ERP-based Employee Leave Management System using Odoo.

The project focuses on analyzing existing leave management processes, identifying business problems, defining requirements, designing improved business processes, and documenting ERP implementation considerations.

The case study simulates an organization that currently manages employee leave requests manually through email and spreadsheets, causing inefficiencies in approval workflows, data tracking, and reporting.

## 🎯 Business Objective

The objective of this project is to analyze and design a centralized employee leave management solution that can:

- Improve leave request and approval workflows
- Reduce manual administrative activities
- Provide better visibility of employee leave data
- Support HR reporting and monitoring
- Enable integrated business processes through ERP implementation

---

## 🔍 Business Analysis Approach

The project follows a structured Business Analysis approach:

1. Business Problem Analysis

2. Stakeholder Analysis

3. Current State Analysis (As-Is Process)

4. Gap Analysis

5. Future State Design (To-Be Process)

6. Requirements Definition

7. Testing & Validation

8. ERP Configuration Documentation

## 📂 Project Documentation

| No | Document | Description |
|---|---|---|
| 01 | Business Problem Analysis | Identifies current problems and business needs |
| 02 | Stakeholder Analysis | Maps stakeholders and their involvement |
